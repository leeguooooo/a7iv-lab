# 自定义快门声音后端状态

尚无可安装并经过实机验收的完整后端。目标是自定义快门声音，保留原厂焦点声音；代码编译、控制回复和原生 Start 返回均不等于出声或资源退休。

## 连续内存校验与有界读取

`sound_span.c` 校验三份单段、各51200字节的数值记录，要求句柄不同、endpoint相同、地址连续且整个153600字节落在已核对的转换窗口内。完整声音仍允许123872字节编码数据和64字节guard。成功结果只描述数值，不授予内存访问或持有权。

`sound_snapshot_model.c` 只读取主机自有的不可变快照。数量不是1时，在读取extent指针前拒绝；地址、记录长度和整数溢出均在访问前检查。三份记录从同一副本解码，任意一份失败都保持输出不变。endpoint只是标签。真实提供者位于独立的`sound_span_unavailable.c`，始终返回UNAVAILABLE，不能由模型测试开启。

运行 `python -m unittest discover -s tests -p test_sound_memory_model.py` 可在没有固件、设备或私有研究目录的环境编译并执行严格C检查、ASan/UBSan检查和提供者符号检查。测试覆盖全部16位数量/状态、代数、短记录、指针边界、失败输出、快照复制、排序和完整5秒容量。原CP研究组件保留旧40字节查询作为历史对照；下面的新派生组件已移除此调用，但尚未纳入安装包。

原厂同步的新增离线证据位于本机`output/sound-native-dmm-lock-20261031/`：10项原始指令用例覆盖同步成功、拒绝、等待与嵌套误释放，其中两项连续执行正常worker的获取、分发、查询与释放。未替换原生同步函数；RTOS对象、CPU0和backing仍为合成数据。查询函数自身不加锁，原厂worker提供外层同步。同步包装器在IRQ禁用、底层获取失败时仍可返回0；在已持锁的worker内再套获取/释放，可能误释放外层锁。因此返回值不能单独证明获取成功，接入时必须核对实际持锁上下文。全部原生修改者、跨端持有与物理播放仍待验证。

## CP独立主引用接入

`sound_cp_backing.c` 新增CP持有机制；默认主机构建始终返回UNAVAILABLE，不执行原生访问。明确选择ARM研究实现后，它只在原厂worker已持有同步的上下文中读取三项单extent记录，复用完整跨度校验，再逐项调用原厂cmd21 flags0增加主引用，并由原厂历史路径记录CP服务source。此操作不调用可变长度的GetExtent回复写入器。完全相同的BIND只复核身份和映射，不重复加引用；中途失败记录已确认与可能取得的引用，永久进入HOLD，不重试或自动释放。

本机`output/sound-primary-retain-20261101/`的9项原始指令检查证明：CP增加主引用后，AP显式按flags2释放，原句柄和extent仍有效；只增加secondary的对照会失效。该结论尚未覆盖endpoint退出或强制清理。

`output/cp-primary-backing-component-20261101/`已将新持有机制接入实际CP owner、编译为Thumb ELF，并通过19项连续指令用例。覆盖原厂队列元数据、worker同步、分配、CP保留主引用、AP显式释放、重复BIND、123872字节上传与64字节guard、COMMIT及84字节原生Start交接；部分失败、无锁上下文、多extent、代数/池错误、不连续地址和原厂kind17冲突均被拒绝，普通声和对焦声保持原厂路径。新增用例先执行原厂ARM清零172字节，再执行Thumb持有、上传和原生交接。此组数据仍为测试图样，末端音频投递和缓存维护仍使用明确替身，未证明真实听音。

新owner为172字节，追加44字节持有记录；支持代码另占1768字节。原厂映射指令核查发现原先11EA10选址为XN，已将支持代码移到相邻BA4B40空洞。`output/cp-primary-backing-layout-20261101/`的10项检查确认：实际FL23基线已将支持段和主代码段映为可执行，无需新加执行权限补丁；原厂基线仍为XN。172字节的声明与实际清零终点必须同时修改，新终点为15644A8，L1/L2基址不变，后方64字节保持。代码空洞独占、完整启动与真实MMU状态仍未证明；完整镜像和更新容器尚未构建。

本轮还复现了本机Unicorn2.1.4的有效内存观察回调干扰：空写回调可改变ITT片段的锁清零结果，空读回调可把BIND位图7改成1。对照保持指令和输入不变，复现文件在该组件目录。19项验证因此不安装有效读写回调，改用代码页只读保护、不可访问的指针边界页、非法访问捕获及执行后原始字节比对；不再声称逐次访问白名单验证。这是本机观察，未断言上游根因或硬件行为。
